## Introducción

Bienvenido al manual de usuario de la aplicación Typewise. Esta aplicación ha sido desarrollada en Javascript y tiene una interfaz gráfica de usuario (GUI) que te permitirá ejecutar código de Typewise y también poder abrir directamente arhivos tw.

## Requisitos del Sistema

Para utilizar esta aplicación web necesitarás:
1. Un dispositivo con acceso a internet: puede ser una computadora, teléfono móvil, tablet, u otro dispositivo que tenga capacidad de conectarse a internet.

2. Un navegador web: el software que se utiliza para acceder y visualizar las páginas web. Los navegadores más populares son Google Chrome, Mozilla Firefox, Safari, y Microsoft Edge.

3. Una conexión a internet: para poder acceder a la página web, se requiere una conexión a internet estable y de alta velocidad.

## Interfaz de Usuario
![Interfaz Gráfica](https://github.com/akamariano/P2_OLCA_202101149/blob/main/interfaztw.png)
![Interfaz Gráfica](https://github.com/akamariano/P2_OLCA_202101149/blob/main/tw2.png)
La interfaz de usuario de la aplicación Typewise se compone de loa siguientes elementos:
1. Editor de Código: permite al usuario indexar desde cero siempre y cuando se respete el lenguaje de codificación un archivo  para ser analizado.
2. Botón abrir: Permite al usuario el despliegue de un explorador de archivos para que peuda seleccionar un archivo existente para su ejecución o edición.
3. Botón Guardar: l modificar un archivo existente o crear uno desde cero permite al usuario guardar los cambios para la ejecución.
4. Botón Analizar: permite al usuario analizar y ejecutar  lo indexado en el editor de código, validando el lenguaje.
5. Botón +/-: Permite añadir nuevas pestañas para su edición y análisis
6. En la parte inferior de la página web se podrá visualizar los gráficos relacionados al archivo ejecutado.
